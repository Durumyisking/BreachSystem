# UV 기반 탄착군과 셀 표시 구현

## 사용자 요청과 범위
- 전역 CellSizeCm을 실제 누적 파손에 연결한다. 가상 격자이며 전체 셀 배열을 만들지 않는다.
- UV 원점과 방향을 기준으로 하되 배치 스케일을 반영한 실제 cm 정사각 셀을 사용한다.
- 같은 셀 안의 탄착은 같은 대표 좌표를 사용하고 피해량은 각각 누적한다.
- 기존 이동 Box/임계값 판정을 유지한다. 동일한 한 번의 파손 후보는 입력 순서와 무관하게 같은 윤곽을 만든다.
- BreachSystem.ShowCell: 무인자 토글, 1 켜기, 0 끄기. 계산에 사용하는 실제 격자를 표시한다.
- 직접 총알 커터, 파괴 후 기록 소비, 네트워크 전송 및 재질별 새 아트 패턴은 이번 변경에서 재설계하지 않는다. 이미 다른 시점에 파손된 벽의 전체 이력은 순서 독립을 보장하지 않는다.

## 구현
1. FBreachCellGrid: UV 선형 변환으로부터 cm 직교 좌표계 생성, 정수 셀/대표점 변환, 유효 범위 검사. UV 전단이 있으면 U방향을 유지하고 V를 직교화한다.
2. Surface: 초기화 시 전역 셀 크기 고정, Reset 후 갱신. 양면이 같은 벽 상태를 공유하므로 -Y 면 UV를 기준으로 사용. 스케일 변경 시 기존 누적 기록을 비우고 고정 셀 크기로 변환 재생성.
3. Accumulator/Shape: 좌표·기여도 기준 정렬, 볼록 외곽 시작점 통일, 누적 윤곽의 0 시드는 안정적인 기본 시드로 해석. 직접 커터의 기존 0 시드 의미는 유지.
4. Debug: 표시 전용 데이터 조회, 별도 라인 배처, 원래 표면·충돌·자산 상태를 바꾸지 않는 콘솔 표시, 종료/월드 수명 정리.

## 검증
- 셀 경계/음수 UV/회전·타일링·전단 UV/비균일·반전 스케일/잘못된 변환 단위 테스트.
- 같은 셀 반복 피해, 첫 파손 탄착 순서 변경, 셀 내부 미세 이동, Reset/새 표면 재현 통합 테스트.
- 기존 BreachSystem 자동화 전체 회귀 확인. 기존 연속 좌표 테스트는 셀 변경의 영향을 격리하도록 명시적 작은 셀 설정 사용.
- 반드시 루트 BuildProject_Editor.bat로 빌드. 필요하면 권한 확장으로 엔진 경로 접근.
- 콘솔 on/off/격자 좌표 검증 및 화면 캡처. 에디터 자산은 저장하지 않는다.
