
### FDynamicMesh3

- **실제 메시 데이터 그 자체**
- 정점, 삼각형, Edge 연결관계 같은 걸 들고 있는 런타임 편집 가능한 삼각형 메시 자료구조
- 벽 메시의 일부를 잘라낸다 할 때 실제로 수정되는 데이터가 이쪽이라고 보면 됨
- `UStaticMesh`처럼 에셋이라기보다 **메모리 안의 편집 가능한 메시 데이터**에 가까움

### UDynamicMeshComponent`
- `FDynamicMesh3`를 **월드에 실제로 보여주고 충돌도 시키는 컴포넌트**
- 내부에 `UDynamicMesh`가 있고, 그 안에 `FDynamicMesh3`가 들어간 구조라고 보면 됨
- `UStaticMeshComponent`가 StaticMesh를 화면에 그리는 역할이라면, 얘는 **수정 가능한 DynamicMesh를 화면에 그리는 역할**
- 메시가 바뀌면 렌더 버퍼 갱신이나 Collision 갱신도 담당할 수 있음


```
FDynamicMesh3
= 실제 정점/삼각형 데이터

UDynamicMesh
= FDynamicMesh3를 UObject로 감싼 컨테이너

UDynamicMeshComponent
= 그 메시를 월드에 렌더링/충돌시키는 컴포넌트
```

### Mesh Boolean

`Mesh Boolean`은 **두 메시를 도형 연산하는 기능**

예를 들어:

```
벽 Mesh A
+
원통 Mesh B
```

가 있으면 Boolean 연산으로:

```
Union
A + B 합치기

Intersect
A와 B가 겹친 부분만 남기기

Difference / Subtract
A에서 B가 차지한 부분 빼기
```

를 할 수 있음.

##### Subtract 
Mesh Boolean의 연산 종류 중 하나
```
Mesh Boolean
├─ Union
├─ Intersection
└─ Difference / Subtract  ← 우리가 주로 사용할 것
```


### Collision Cooking

예를 들어 처음 벽이:

```
████████████
```

이었고 Boolean을 해서 렌더 메시가:

```
████    ████
```

이렇게 됐다고 해도, 기존 Collision을 그대로 쓰면 물리적으로는 여전히:

```
████████████
```

일 수 있음
그래서 변경된 메시를 기반으로 **Physics Collision 데이터를 다시 만들어야 함**

`UDynamicMeshComponent`는 현재 메시를 Complex Collision 소스로 사용할 수 있고, `UpdateCollision()`으로 Physics/Collision 데이터를 다시 생성할 수 있어. Async Cooking도 지원
