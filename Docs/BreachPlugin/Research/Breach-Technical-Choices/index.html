TECHNICAL NOTE 01

세 기술을 선택하기 위한 지도

상용 에셋 → 재질 데이터 → 누적 손상과 외곽 → 제거 영역의 조각.

권장 시작 조합

상용 에셋을 에디터에서 분석·베이크하고, 실행 중에는 희소한 표면 피해장으로 손상을 누적한 뒤 외곽을 추출한다. 제거된 영역은 2D 보로노이로 나누고 벽 두께만큼 확장한다. 이것은 구현 후보 조합이며 R6의 실제 내부 구현을 추정한 결론이 아니다.

대상은 요청한 세 가지 기술뿐이다. ① 재질 기반 절삭의 입력을 어떻게 얻는가, ② 탄착을 어떻게 모으고 복잡한 구멍을 만드는가, ③ 제거 영역을 어떻게 보로노이 파편으로 바꾸는가. 서버·충돌은 이 기술의 선택에 영향을 주는 조건만 적고 별도 시스템 설계로 확대하지 않는다.

1 · 재질 입력 방법2-A · 점·피해 모으기2-B · 구멍 외곽 만들기3 · 파편 분할 방법조합 비교와 선택표

‘상용 에셋이니 덜 효율적’은 필연이 아니다

상용 텍스처·메시의 복잡함을 매 피격마다 분석하면 비용이 늘어난다. 반면 에디터에서 한 번 분석해 간단한 라벨·방향장·벡터 경계로 바꾸면, 런타임은 그 결과만 조회한다. 차이는 입력 에셋의 출처보다 분석 시점, 런타임 표현, 해상도와 경계 복잡도에 있다.

사용자가 전용 파괴 에셋을 손으로 새로 제작할 필요는 줄일 수 있다. 다만 플러그인이 자동 생성하는 파괴용 파생 데이터까지 없애야 하는 것은 아니다. 원본 에셋은 보존하고, 파생 데이터의 버전·해시·재생성 조건을 관리하는 방식을 권한다.

이 문서의 성능 표현

밀리초·FPS는 Unreal에서 측정하지 않았으므로 제시하지 않는다. 대신 알고리즘의 입력 크기, 연산량, 메모리 산식, 비용을 키우는 조건을 적었다. 예시 수치는 설명용 설정 또는 직접 계산한 도형 결과이며, R6 상수나 최종 성능 예측치가 아니다.

문헌: 공개 알고리즘 성질로컬 확인: UE 5.8.2 소스제안: 우리 제품의 선택지계산 예시: 합성 입력 결과

TECHNICAL NOTE 02

공통 입력·출력부터 분리한다

기술을 교체해도 뒤 단계가 그대로 연결되도록 하는 최소 계약.

표면 좌표·재질 조회→손상 갱신→제거 영역 결정→벽 차집합→제거 영역 분할

기하의 기준은 기존 프로젝트와 같은 표면 로컬 2D + 두께로 둔다. 재질 패턴의 UV와 탄착 위치를 이 좌표계에 연결한다. 아래 데이터 이름은 설명용이며 C++ 선언을 확정한 것은 아니다.

데이터담을 의미주의
표면·매핑남은 다각형, 두께, 표면→UV/재질 조회바깥 경계뿐 아니라 내부 구멍·분리 영역도 유지
재질 파생 데이터영역 ID, 경계, 방향, 설계자가 정한 강도PBR Roughness나 밝기가 실제 파괴 강도를 뜻하지 않음
공격·누적 상태위치·세기·범위·순번, 누적값 또는 탄착 목록같은 위치의 반복 공격을 데이터 중복과 혼동하지 않음
절삭 결과남은 영역과 이번에 제거한 영역이전에 이미 빈 곳을 다시 파편으로 만들지 않음
R_before = 절삭 전 실제 남은 표면
C        = 이번 입력으로 확정한 제거 요청 영역
R_after  = R_before − C              // 추가 탈락 정책이 있으면 여기에 반영
Removed  = R_before − R_after        // 실제로 새로 없어진 영역
Fragment_i = Removed ∩ VoronoiCell_i

현재 코드는 차집합 뒤 원본 외곽에 닿지 않는 영역도 제거한다. 이 정책을 유지한다면 그 부분도 Removed에 포함해야 한다. 구조적으로 떨어진 큰 조각을 그대로 남길지 다시 분할할지는 별도 정책이며, 단순 교집합 R_before ∩ C만으로는 추가 탈락을 모두 담지 못한다.

TECHNICAL NOTE 03

1 · 재질 데이터를 얻는 다섯 가지 방법

기본 패턴, 보조 맵, 자동 분석, 메시 구조, 최종 재질 베이크.

재질 기반 절삭은 화면의 재질과 대응하는 데이터가 절삭의 위치·방향·범위·경계 선택에 관여하는 것이다. 셰이더에 색을 지우는 마스크를 넣는 것만으로 실제 폴리곤 절삭이 완성되지는 않는다.

입력 데이터 확보와 파괴 규칙은 두 선택이다. 예를 들어 벽돌 영역을 자동 인식했더라도 “맞은 벽돌 전체 제거”, “원래 공격 범위만 제거”, “줄눈을 따라 경계를 확장” 중 어느 동작을 할지는 별도로 정해야 한다.

M1

매개변수로 만드는 재질 패턴

수작업을 최소화하고 바로 시작할 때. 나무·벽돌의 전형적인 형태를 빠르게 제공.

만드는 방법

목재는 결 방향·간격·방향 편차를, 벽돌은 폭·높이·줄눈·엇갈림을 입력받아 표면/UV 공간에 패턴을 만든다. 공간 해시로 고정한 변동을 더할 수 있다. 세부 패턴은 공격마다 새로 흔들지 않고 표면에 고정한다.

나오는 결과

목재는 방향성 있는 긴 파단, 벽돌은 층과 줄눈에 맞춘 계단형 경계를 만들 수 있다. 실제 상용 텍스처의 벽돌 모양과 자동으로 일치하는 것은 아니다.

성능 특성

텍스처 분석이 없고, 계산식으로 필요한 주변 패턴만 생성 가능. 단순 그리드 라벨 조회는 상수 시간으로 설계할 수 있으나 최종 경계 연산은 선택 영역 수에 따라 증가한다.

실패 조건 / 선택의 대가

기울어진 판자·불규칙 조적·옹이처럼 실제 텍스처의 구조가 모델과 다르면 시각적 어긋남. 크기·오프셋을 맞추는 작업은 필요하다.

M2

기존 Height·Mask에서 영역 추출

경계가 나타나는 높이맵이나 ID/마스크가 함께 제공되는 상용 텍스처에 적합.

만드는 방법

에디터에서 원본 데이터를 읽고 노이즈 제거 → 임계값/마커 생성 → 연결 성분 또는 watershed → 영역 라벨 → 경계 벡터화·단순화를 수행한다. 단순한 벽돌에서는 줄눈 후보를 높이·색 신호로 만들고 잘못된 합침만 수정한다.

나오는 결과

실제 텍스처와 대응하는 벽돌·판재 단위 또는 약한 경계의 위치를 얻는다. 원본을 다시 그리지 않고 파생 데이터로 저장한다.

성능 특성

분석 비용은 에디터로 이동. 런타임 라벨 조회는 정해진 격자에서 O(1), 선택한 경계 수에 따른 폴리곤 연산이 남는다. 저장비용은 해상도와 라벨/경계 표현에 따라 달라진다.

실패 조건 / 선택의 대가

Height가 있어도 실제 재료 구분을 보장하지 않는다. 표면 요철·얼룩을 조각 경계로 오인할 수 있다. 작은 섬 제거와 타일 이음새 보정, 최소한의 사용자 확인이 필요하다.

기술 근거: OpenCV · Marker-based Watershed

M3

Albedo·Normal 등에서 자동 후보 추정

보조 마스크 없이 상용 PBR 묶음을 최대한 활용하고 싶을 때.

만드는 방법

색/밝기·색차·높이/법선 변화에서 경계 후보를 만들고, 마커 기반 분할이나 영역 병합으로 라벨화한다. 목재 방향은 영상 기울기의 구조 텐서로 주방향과 일관성을 계산하는 방법을 쓸 수 있다. 신뢰도가 낮은 곳은 수동 방향 또는 M1로 대체한다.

나오는 결과

벽돌의 실제 줄눈이나 나무 무늬의 방향에 맞춘 초기 후보. 목재는 완전한 조각 라벨 대신 연속적인 방향장만 얻어도 절삭에 사용할 수 있다.

성능 특성

에디터 분석 비용·임시 이미지 메모리가 증가한다. 런타임에는 M2와 같은 파생 데이터를 쓰면 원본 이미지 분석 비용이 남지 않는다. 모델 기반 분할을 추가한다면 별도의 도구 의존성이 생긴다.

실패 조건 / 선택의 대가

그림자·칠·오염·압축 노이즈·무늬가 물리 재료 경계와 같지 않다. 자동 정확도를 임의의 %로 약속할 수 없다. 방향장도 실제 내부 섬유 강도를 측정한 값이 아니며 물리 상수는 직접 설정해야 한다.

기술 근거: OpenCV · Structure Tensor 방향·일관성 추정

M4

메시의 분리 부품·면 그룹 활용

상용 메시가 판자·벽돌 등 실제 부품으로 구성된 경우에 적합.

만드는 방법

연결 성분, 평면 면 그룹, material slot, 기존 vertex color·ID 등의 단서를 읽어 표면별 영역을 만든다. UV seam은 후보로만 사용한다. 단일 벽면을 투영해 2D 영역과 원본 삼각형 매핑을 베이크한다.

나오는 결과

실제 모델링된 판자·부품 경계와 파괴 단위를 맞출 수 있다. 텍스처에서 의미를 추론하는 부담이 줄어든다.

성능 특성

에디터 전처리는 삼각형 수·인접성 계산과 공간 인덱스 비용. 런타임은 영역 수와 선택 영역에 좌우된다. 원본 고해상도 메시 전체를 매번 변환하지 않도록 한다.

실패 조건 / 선택의 대가

material slot이나 UV island는 제작 편의를 위한 구분일 수도 있다. 삼각형 하나를 파괴 셀로 쓰면 삼각분할 흔적이 결과에 나타난다. 경계가 없는 단일 평면 메시에서는 얻을 구조 정보가 적다.

M5

최종 머티리얼을 표면 공간에 베이크

복잡한 머티리얼 그래프·레이어 혼합·월드 정렬 텍스처를 받아야 할 때.

만드는 방법

에디터에서 선택 표면의 머티리얼 속성 또는 사용자가 지정한 출력 신호를 고정 좌표계에 베이크한다. 그 결과에 M2/M3 분석을 적용한다. 위치·회전·머티리얼 파라미터 등 베이크에 영향을 준 값을 캐시 키에 넣는다.

나오는 결과

텍스처 한 장의 원본 UV로 표현할 수 없는 최종 외관과 분석 입력을 연결한다. 파괴 데이터는 서버도 읽을 수 있는 CPU 데이터로 저장한다.

성능 특성

베이크·읽기·분석 비용은 에디터에서 발생. 실행 중 GPU readback을 피할 수 있다. 인스턴스마다 다른 월드 정렬 결과라면 파생 데이터 공유가 줄어들어 저장 공간이 늘 수 있다.

실패 조건 / 선택의 대가

베이크는 의미를 이해하지 않는다. 시간·카메라·월드 위치에 따라 변하는 재질은 어느 상태를 기준으로 할지 정해야 한다. 임의의 머티리얼을 변동 없이 완벽하게 지원한다고 약속하면 안 된다.

기술 근거: Epic · Merging Actors / 재질 베이크

비교 기준: 전용 벡터 패턴을 직접 저작하는 방법

직접 만든 라벨·벡터 패턴은 의미와 경계를 명확히 정할 수 있어 기준 품질을 만들기 좋다. 다만 모든 사용자가 이를 새로 만들어야 한다면 상용 에셋을 바로 쓰려는 목표에 맞지 않는다. M1 기본값, M2/M3 자동 생성, 최소 수정, 고급 사용자용 수동 입력을 함께 제공하는 구성이 적합하다.

권장 사용자 흐름

원본 메시·재질 선택→표면/텍스처 신호 자동 탐색→라벨·방향 후보 생성→오버레이 확인·일부 수정→파생 데이터 베이크

파생 데이터는 원본 텍스처/메시 변경 시 재생성한다. 런타임 모듈은 원본 분석기나 에디터 의존성을 요구하지 않게 구성한다. “아무 에셋이나 무설정으로 정확히 인식”을 제품 조건으로 잡지 않는다.

TECHNICAL NOTE 04

1 · 상용 메시·UV를 받아들이는 구체적 처리

재질 패턴을 얻는 것보다 좌표를 정확히 연결하는 일이 먼저다.

평면형 상용 메시를 지원하는 최소 경로

  1. 사용자가 파괴할 면 그룹을 선택하거나 평면 후보를 검출한다. 삼각형 법선·연결성과 평면 적합 오차로 후보를 묶되, 오차 허용치를 설정값으로 둔다.
  2. 선택한 면의 경계와 내부 구멍을 추출하고 기준 평면에 투영한다. 단순 AABB 사각형으로 대체하면 원본의 비사각 경계가 사라진다.
  3. 반대 면과 두께가 명확한 경우 자동 추정하고, 불명확하면 사용자 두께 또는 명시적 절삭 프록시를 사용한다. 곡면·가변 두께·닫히지 않은 임의 메시를 같은 경로로 처리한다고 주장하지 않는다.
  4. 원본 삼각형·UV·material slot의 대응을 저장한다. 2D 삼각형 공간 인덱스로 피격점이나 생성 정점이 어느 원본 면에 대응하는지 찾는다.
표면 점 p가 원본 삼각형에 속할 때:
p = b0·p0 + b1·p1 + b2·p2,   b0+b1+b2 = 1
uv(p) = b0·uv0 + b1·uv1 + b2·uv2
실제 조회 좌표 = 지원하는 Scale / Offset / Rotation을 반영한 uv(p)

하나의 평면에서도 UV가 여러 island로 나뉘거나 다른 비율을 가질 수 있다. 이때 전체 벽에 하나의 선형 UV 변환만 쓰면 맞지 않는다. 삼각형별 매핑 또는 표면 공간 베이크 중 하나를 택한다. 절단면에는 별도 UV 규칙이 필요하다.

상황처리 선택놓치면 생기는 문제
반복 타일·음수 UVwrap 처리와 타일 위치를 포함한 영역 ID, 경계 횡단 라벨 병합 규칙같은 텍스처의 다른 벽돌이 같은 손상 상태를 공유하거나 이음새에서 쪼개짐
겹친·미러 UV표면/차트 구분 + 미러 방향 보정다른 위치가 함께 파괴되거나 결 방향이 반전됨
비균일 스케일물리 길이 기준으로 거리·커널 정의, 매핑의 Jacobian 확인텍스처 해상도와 스케일에 따라 피해 반경이 달라짐
WorldAligned·복합 레이어지원한 좌표식을 직접 구현하거나 M5 베이크보이는 무늬와 CPU 절삭 위치 불일치

저장할 정보는 목적별로 다르다

라벨 지도는 어느 판자/벽돌인지, 방향장은 어느 방향으로 길게 반응할지, 강도장은 어느 지점에서 파괴가 더 쉬운지를 표현한다. 셋을 같은 흑백 값으로 취급하지 않는다. 강도장은 물성 측정치가 없으면 게임 규칙으로 저작한 값이라고 표시한다.

목재의 영상 방향 추정에는 구조 텐서의 고유벡터와 방향 일관성을 사용할 수 있다. 영상 기울기 방향은 결 방향과 수직일 수 있어 어떤 고유벡터를 쓸지 확인해야 한다. UV 방향을 표면 방향으로 옮길 때는 해당 매핑의 역변환을 사용하고, 특이하거나 왜곡된 매핑은 fallback 처리한다.

재질 데이터가 최종 외곽에 관여하는 세 방식

방식구현결과와 비용
영역 단위 제거피해 조건을 만족한 라벨/셀의 경계를 합집합벽돌·판자 경계를 강하게 유지. 셀 크기만큼 파괴가 크게 뛰는 계단 현상
국소 강도·방향 변조피해장 임계값 T(x), 커널 거리 M(x)에 재질 정보 반영탄착 배치와 재질 방향을 함께 반영. 격자 해상도와 샘플링 비용 필요

2-A · 점을 모으거나 피해를 누적하는 네 방법

같은 발수라도 위치·밀도·재질이 다르면 다른 결과가 나와야 한다.

군집화는 어떤 점들이 함께 작용하는지 결정하고, 외곽 생성은 그 점들에서 어떤 영역을 제거할지 결정한다. DBSCAN을 호출했다고 폴리곤이 생기지 않는다. 피해장 방식은 명시적인 점 군집 없이도 임계값과 연결 성분으로 영역을 얻을 수 있다.

C1

공간 해시 + 거리 그래프

명확한 근접 거리 규칙과 단순한 구현이 우선일 때.

만드는 방법

표면 좌표를 셀에 넣는다. 셀 폭=ε라면 새 점의 셀과 주변 8셀에서 후보를 찾고 거리≤ε인 점과 연결한다. Union-Find 또는 BFS로 연결 성분을 얻는다. 군집의 피해량은 별도로 누적한다.

나오는 결과

서로 가까운 점들의 연결 무리. 이어진 탄착 열의 방향을 유지하며 별도 외곽 알고리즘에 전달할 수 있다.

성능 특성

균일하게 분산되고 셀당 점 수가 작으면 조회는 주변 후보 k에 비례한다. 전체 구성은 대략 O(n+e)에 Union-Find 비용이 붙는다. 한 셀에 몰리면 후보·간선 수가 O(n²)까지 증가한다.

실패 조건 / 선택의 대가

A-B, B-C가 가까우면 A-C가 멀어도 같은 군집이 된다. 이 군집 전체 피해만으로 파괴를 판정하면 긴 사슬이 부당하게 큰 구멍을 만들 수 있다. 최대 확장 거리나 국소 피해 검사가 별도로 필요하다.

C2

DBSCAN 밀도 기반 군집

희박한 연결점과 고립점을 어느 정도 제외하고, 밀집된 탄착 무리를 추출할 때.

만드는 방법

ε 이웃 안의 점 수가 minPts 이상인 점을 core로 삼고 core 연결을 확장한다. 주변 border 점과 noise를 구분한다. 여기서 minPts는 자신 포함 기준으로 통일한다. 피해량 가중과 점 개수는 다른 정책으로 취급한다.

나오는 결과

좁게 모인 두 무리는 유지하면서 성긴 연결 사슬 일부를 noise/border로 처리할 수 있다. 다만 충분히 조밀한 사슬은 여전히 군집을 연결한다.

성능 특성

공간 인덱스와 분포가 적절하면 검색 부담을 줄일 수 있지만 모든 경우 O(n log n)을 보장하지 않는다. 전체 이웃 목록을 저장하는 구현은 밀집 입력에서 O(n²) 메모리가 될 수 있다.

실패 조건 / 선택의 대가

ε·minPts 튜닝이 필요하다. border가 여러 군집에 닿으면 처리 순서에 따른 귀속 차이를 처리해야 한다. 반복 동일 좌표를 압축했다면 발수/가중치를 따로 보존한다. 프레임마다 모든 점을 재군집화하는 구현은 누적될수록 비싸진다.

기술 근거: DBSCAN 원 논문 · Ester et al., 1996 · scikit-learn · DBSCAN 파라미터와 메모리 주의

C3

희소 격자에 누적하는 피해장

반복 탄착·무기별 피해·재질 방향을 하나의 표현으로 다루고 싶을 때. 권장 출발 후보.

만드는 방법

각 탄착을 유한 반경의 커널로 주변 격자에 더한다. D(x)≥T(x)인 영역이 큰 파괴의 후보가 된다. 필요한 타일만 할당하고 입력 주변을 갱신한다. 원래의 작은 총탄 구멍은 별도 정밀 폴리곤으로 유지한다.

나오는 결과

가까운 점의 영향이 겹치면 제거 영역이 커지고, 떨어진 점의 영향이 겹치지 않으면 별도 영역으로 남는다. 같은 위치의 반복 사격도 누적량이 증가한다.

성능 특성

한 발은 지원 반경 내 A개 샘플을 갱신하므로 O(A). A는 대략 π(R/h)²이고 벽 전체 크기와 독립적으로 제한할 수 있다. 외곽 추출·연결 성분 재계산·영역 합치기 비용은 별도로 든다.

실패 조건 / 선택의 대가

거친 격자는 작은 구멍과 얇은 연결을 잃는다. 모든 총탄 디테일을 이 격자로 표현하지 않는다. 타일 경계 halo와 대각 연결 규칙, 임계 부근 떨림, 손상 보존/소비 정책을 명시해야 한다.

C4

재질 셀·인접 그래프에 피해 누적

벽돌·판자 등 의미 있는 파괴 단위가 먼저 확보된 경우.

만드는 방법

라벨로 만든 영역을 노드, 맞닿은 경계를 간선으로 둔다. 공격과 겹치는 셀에 피해를 분배하고, 재질/연결 규칙으로 추가 셀을 선택한다. 선정된 셀의 합집합이 외곽이 된다.

나오는 결과

재질 경계와 일치하는 큰 조각·계단형 구멍. 국소 탄착에서도 설정에 따라 셀 단위의 큰 파괴를 만들 수 있다.

성능 특성

선택·전파한 노드와 간선 수가 주 비용이다. 런타임 이미지 분석이 필요 없다. 셀 경계가 복잡하거나 광범위한 전파가 생기면 Boolean 입력이 커진다.

실패 조건 / 선택의 대가

셀 크기·면적에 피해를 어떻게 배분할지 결정해야 한다. 큰 셀 전체가 한꺼번에 없어지는 모습이 목표와 맞지 않을 수 있다. 목재는 셀 내부 미세 절삭과 결 방향 반응을 함께 지원할 수 있어야 한다.

2-A · 피해장을 실제로 정의하는 예

수식은 구현 후보의 정의이며, R6에서 가져온 공식이 아니다.

q_i(x) = ||x − p_i||² / R_i²
K(q)   = (1 − q)²,  0 ≤ q < 1
         0,         q ≥ 1
D(x)   = Σ w_i · K(q_i(x))
CandidateHole = { x | D(x) ≥ T(x) }

p_i는 탄착점, w_i는 설계한 피해량, R_i는 영향 반경, T(x)는 파괴 임계값이다. 커널이 유한 반경 밖에서 0이므로 아주 먼 탄착의 약한 꼬리가 무한히 합산되지 않는다. 총탄의 미세 구멍 반경과 R_i는 서로 다른 설정이다.

목재 방향은 결의 평행·수직 성분으로 나누어 q=(d∥/R∥)²+(d⊥/R⊥)²로 정의할 수 있다. 공간마다 방향이 바뀌면 단순 타원 하나로 끝나지 않고 위치별 매핑·갱신 규칙이 필요하다. 이것은 게임용 방향성 모델이며 물리 응력 해석이 아니다.

같은 위치 반복 사격이 커지는 이유

n발이 완전히 같은 위치이고 각 피해가 1이면 D=n·K다. n>T일 때 경계 반경은 r=R·√(1−√(T/n))가 된다. 따라서 반복 사격으로 넓어지지만 항상 R 안에 머문다. 국소 탄착이 그보다 훨씬 큰 재질 조각을 떼어내려면 C4 같은 별도 확장 규칙이 필요하다.

시간·파괴 이후 상태도 규칙이다

손상을 유지할지 감쇠시킬지, 제거된 부분의 손상을 지울지, 주변에 남은 손상은 유지할지 정해야 한다. 단순히 매번 현재 피해장에서 구멍을 다시 만들면 감쇠 때 벽이 복구되는 문제가 생긴다. 영구 절삭이라면 이미 제거한 영역은 유지하고 새로 추가된 제거 영역만 적용한다.

좌표 양자화·정수 누적을 쓰면 저장·재현의 규칙을 명시하기 쉬워진다. 다만 실수 커널 샘플링, 최대값 포화, 감쇠, 소비까지 포함한 순서가 같아야 한다. 정수화나 seed 하나만으로 플랫폼 간 전체 결과 동일성을 보장했다고 볼 수 없다.

작은 구멍과 큰 구멍의 표현 해상도를 분리한다

수 mm 수준의 미세 절삭을 벽 전체의 피해장 격자로 표현하면 저장량이 급증한다. 제안은 작은 총탄 절삭은 기존 벡터 경계, 큰 파괴 판정은 더 거친 국소 피해장으로 나누는 것이다. 두 결과를 실제 남은 표면에 함께 적용하고, 서로 겹치는 영역은 Boolean으로 정리한다.

TECHNICAL NOTE 07

2-B · 복잡한 다각형 외곽을 만드는 여섯 방법

군집을 얻은 뒤에도 외곽을 어떻게 정의할지 별도로 선택해야 한다.

외곽은 언제나 하나의 단순 다각형이 된다고 가정하면 안 된다. 탄착이 떨어져 있거나 가운데에 남은 부분이 있으면 여러 영역과 내부 구멍이 필요하다. 강제로 하나의 외곽으로 연결하면 맞지 않은 벽까지 제거한다.

O1

Convex Hull + Offset

비교용 기준 구현 또는 볼록한 큰 구멍만 필요한 경우.

만드는 방법

군집 점의 볼록 껍질을 구하고 여유 폭을 준다. 단일점·두 점은 원 또는 캡슐로 별도 처리한다.

나오는 결과

입력 전체를 감싸는 큰 볼록 구멍. U자 탄착의 가운데 빈 공간도 채워진다.

성능 특성

일반적인 2D hull 구축 O(n log n). 출력 경계가 작아 후속 Boolean·삼각분할 부담을 제한하기 쉽다.

실패 조건 / 선택의 대가

오목한 윤곽과 내부 구멍을 표현하지 못한다. 점들 사이 넓은 미피격 영역을 제거할 수 있어 사용자 사진의 일반 해법으로 권하지 않는다.

O2

원·타원·캡슐의 합집합

가장 직접적으로 기존 폴리곤 절삭을 확장할 때.

만드는 방법

탄착마다 반경을 가진 원/타원을 만들고 합집합한다. 필요한 연결 구간만 캡슐로 이을 수도 있다. 원은 일정 오차 이하의 다각형으로 근사한다.

나오는 결과

탄착을 따라 오목한 외곽이 생기고 떨어진 무리는 별도 구멍으로 남는다. 그대로 두면 원들이 겹친 둥근 물방울 모양이 잘 드러난다.

성능 특성

점 n개, 원당 v정점이면 초기 경계가 약 n·v개. 교차 수·접촉·누적 히스토리에 따라 Boolean 비용이 증가한다. 처리한 모든 원을 매번 다시 합치지 않는 갱신 경로가 필요하다.

실패 조건 / 선택의 대가

똑같은 원을 다시 합쳐도 모양은 안 커진다. 반복 사격의 누적 피해는 C3/C4 또는 별도의 성장 규칙이 필요하다. 원 근사 정점을 과도하게 늘리면 경계 비용이 불필요하게 커진다.

O3

Alpha Shape / Concave Hull 계열

점 분포의 오목한 형태를 직접 복원하고 싶을 때.

만드는 방법

Delaunay 삼각분할에서 크기 조건을 만족하는 삼각형·단체를 선택해 경계를 얻는다. 2D 면적이 필요하면 regularized 정책과 작은 팽창을 검토한다. α의 단위·방향은 라이브러리별 정의를 확인한다.

나오는 결과

볼록 껍질보다 탄착 분포의 빈 공간과 오목부를 남길 수 있다. 설정에 따라 여러 영역·구멍·면적 없는 선 조각이 생긴다.

성능 특성

Delaunay 구축은 일반적인 평면 입력에서 O(n log n) 계열, 이후 경계 추출은 선택된 단체에 비례한다. 퇴화 처리·offset·정리 비용은 추가된다.

실패 조건 / 선택의 대가

거의 일직선인 총탄 열이나 좁게 모인 소수점은 넓은 구멍을 만들 근거가 없다. 반복 동일 좌표도 별도 피해 상태 없이는 크기가 늘지 않는다. 게임용 누적 피해를 대체하는 알고리즘은 아니다.

기술 근거: CGAL · 2D Alpha Shapes

O4

누적 피해장 + Marching Squares

C3와 직접 연결. 위치·세기·재질 변조를 함께 반영하려는 경우.

만드는 방법

격자 꼭짓점의 D−T 부호를 읽고 셀 변에서 선형 보간해 등치선을 만든다. 선분을 폐곡선으로 연결하고 바깥 경계/구멍을 분류한 뒤 필요 범위에서 단순화한다.

나오는 결과

탄착 밀도에 따라 부드럽게 연결되는 복잡한 윤곽. T(x)나 방향장·고정된 공간 변동을 통해 재질에 따른 변화를 줄 수 있다.

성능 특성

방문한 격자 셀 수 G에 대해 추출 O(G), 나온 경계 B에 따라 연결·정리 비용 발생. h를 절반으로 줄이면 같은 면적의 격자 비용은 약 4배다.

실패 조건 / 선택의 대가

대각선의 두 양성 꼭짓점이 마주 보는 모호한 경우에 연결 규칙을 고정해야 한다. ROI/타일 경계의 열린 등치선, 얇은 목 손실, 내부 구멍 처리와 halo가 필요하다. coarse grid가 곧 자연스러운 파단 디테일은 아니다.

기술 근거: scikit-image · find_contours / Marching Squares

O5

형태학적 Closing / 제한적 경계 정리

O2/O4의 작은 틈·과도한 요철을 정리하는 후처리.

만드는 방법

Closing은 영역을 반경 r만큼 팽창한 다음 같은 크기로 침식한다. 벡터 offset 또는 래스터 morphology로 수행한다. 그 뒤 허용 오차 내에서 경계 정점을 줄인다.

나오는 결과

작은 틈이 메워지고 가까운 덩어리가 연결되며 잘게 파인 부분이 완화된다. 기존 shape 위에 독립적인 정리 규칙을 얹는다.

성능 특성

래스터는 처리 픽셀과 커널 구현, 벡터는 offset으로 생긴 정점·교차에 따라 비용 증가. 정점 감소가 이후 단계 비용을 줄일 수 있으나 추가 연산 자체도 측정해야 한다.

실패 조건 / 선택의 대가

너무 큰 r는 실제 남겨야 할 틈과 구멍을 없앤다. 단순화도 면적·최소 폭·위상을 바꿀 수 있다. “노이즈를 줬다”는 이유로 폴리곤 자기 교차를 허용하지 않는다.

기술 근거: Shapely · 도형 연산·단순화·예제 계산

O6

선택된 재질 셀의 합집합 / 경계 유도

판재·벽돌 무늬가 최종 외곽을 강하게 결정해야 할 때.

만드는 방법

C4에서 선택한 셀을 합치거나, C3의 후보 영역과 재질 셀의 겹침 비율을 계산해 전체·부분 제거를 선택한다. 일부만 재질 경계로 이동시키려면 최대 이동거리와 연결 규칙을 둔다.

나오는 결과

길게 찢어진 목재 또는 층을 따르는 벽돌 윤곽. 선택 범위와 셀 크기에 따라 작은 입력에서 큰 조각이 제거되는 결과도 설계 가능하다.

성능 특성

조회한 셀 수 s와 셀 경계 총 정점 B에 비례한 입력이 생긴다. 공간 인덱스·미리 단순화한 셀 경계로 줄일 수 있다.

실패 조건 / 선택의 대가

셀 전체 제거는 계단식 변화가 크다. 줄눈/접착 영역을 남길지 제거할지 정해야 한다. 재질 경계 정렬은 일반적인 단순 offset보다 위상 검증이 어렵다.

거친 외곽은 마지막 한 겹이다

주어진 큰 외곽에 정점 노이즈만 추가하는 방법은 미세 거칠기를 만들 수 있지만, 누적 피해·재질 셀 선택·큰 오목부의 원인을 대신하지 않는다. 변동을 추가한다면 이벤트별 난수만 쓰기보다 표면 좌표에 고정한 패턴, 진폭 제한, 자기 교차 검사와 단순화를 함께 설계한다.

TECHNICAL NOTE 08

1과 2를 결합하는 세 구성

모든 방법을 동시에 구현하기보다, 원하는 조절 방식에 맞는 조합을 고른다.

A · 벡터 중심

자동 재질 패턴 + 거리 군집 + 도형 합집합

M2/M3 → C1 → O2 + 필요한 범위의 O6. 기존 폴리곤 경로를 가장 직접적으로 활용한다. 점 목록과 주변 검색, 원형 커터 합집합부터 검증하기 쉽다.

비용의 약점은 많은 탄착에서 경계 정점과 교차가 늘어나는 점이다. 누적 타격으로 큰 구멍이 되는 규칙을 별도로 정해야 하며, 군집 피해 총량만으로 넓은 사슬을 제거하지 않도록 한다.

B · 권장 시험 후보

자동 재질 데이터 + 희소 피해장 + 등치선

M2/M3/M5 → C3 → O4 → 필요할 때 O6. 탄착의 위치·피해량·재질 방향을 연속적으로 조절하기 쉽다. 미세 탄흔은 벡터, 큰 파괴 판정은 격자로 분리한다.

해상도·ROI·타일 경계와 윤곽 단순화를 직접 관리해야 한다. 시연 그림처럼 기본 커널만 쓰면 부드러운 윤곽이 나오므로, 재질 경계 또는 고정된 강도 변동을 추가하는 단계가 필요하다. 성능 우승이라고 확정한 조합은 아니다.

C · 재질 단위 중심

재질 영역 그래프 + 셀 피해 + 영역 합집합

M2/M4 → C4 → O6. 벽돌·판자 단위의 의미가 중요한 경우다. 어느 조각이 왜 떨어졌는지 설명하기 좋고, 정밀한 래스터 손상장을 반드시 유지할 필요는 없다.

영역 데이터 품질에 의존하며 셀 내부 파괴와 셀 전체 탈락을 나누어야 한다. 큰 판자에 작은 타격이 들어왔을 때 항상 판자 전체가 사라지지 않도록 미세 절삭 경로를 유지한다.

구현 전에 비교할 작은 시험

동일 표면·탄착 이력으로 A와 B를 먼저 비교하고, 목재·벽돌의 재질 단위가 중요할 때 C를 추가한다. 비교 입력은 같은 위치 반복, 가로·세로 열, U자 배치, 멀리 떨어진 두 무리, 사슬로 연결된 두 무리, 재질 경계의 양옆이다. 외곽·남은 구멍·처리량·정점 수를 함께 기록한다.

TECHNICAL NOTE 09

3 · 제거 영역의 보로노이 파편화

일반 2D, 방향성 2D, 가중, 실제 3D를 구분해 선택한다.

이 단계에서는 구멍 외곽이 이미 정해져 있다. 보로노이의 역할은 제거된 영역의 내부를 여러 조각으로 나누는 것이다. 보로노이 셀 전체를 곧바로 메시로 만들지 말고 반드시 제거 영역과 교차해야 한다.

V1

2D 보로노이 → 제거 영역 교차 → 두께 확장

현재 평면형 벽에 가장 직접적인 출발 방법.

만드는 방법

제거 영역 안에 seed를 배치한다. 2D Delaunay의 dual이나 반평면 교차로 셀을 만들고, 각 셀을 Removed와 교차한다. 결과의 각 연결 성분을 삼각분할한 뒤 앞·뒤·측면을 생성한다.

나오는 결과

판을 조각낸 형태. 파편의 전·후면이 같은 2D 윤곽이고 옆면은 두께 방향으로 이어진다. 내부 구멍과 오목 경계를 보존할 수 있다.

성능 특성

효율적인 일반 2D 구성은 O(k log k) 계열이며, 실제 전체 비용은 k개 셀의 경계 교차·삼각분할·메시 생성까지 포함한다. 벽 전체가 아니라 Removed만 처리한다.

실패 조건 / 선택의 대가

하나의 볼록 셀도 오목한 Removed와 만나 여러 조각으로 나뉠 수 있다. 셀 1개=파편 1개라고 가정하면 안 된다. 교차 결과가 오목하면 간단한 삼각형 fan이나 단일 convex collision으로 대체하면 형상이 달라진다.

V2

방향성 2D 보로노이

목재처럼 길쭉한 조각을 원할 때.

만드는 방법

결 방향에 맞춘 좌표축에서 한 축을 압축한 공간으로 seed와 영역을 옮겨 보로노이를 만들고 다시 역변환한다. 또는 양의 정부호 거리 행렬 M을 사용한다. 모든 셀에 같은 M을 쓰는 경우부터 시작한다.

나오는 결과

특정 방향으로 긴 조각. 일반 보로노이보다 목재 방향을 표현하기 쉬운 제어 수단이다. 실제 섬유 파괴를 물리적으로 재현한다는 뜻은 아니다.

성능 특성

일정한 affine 변환이면 일반 2D 방식과 같은 차수이며 변환 비용이 더해진다. 공간적으로 변하는 방향장은 단순 전역 변환으로 해결되지 않는다.

실패 조건 / 선택의 대가

강한 이방성은 매우 얇고 긴 파편을 만든다. 최소 폭·면적, 슬리버 병합, 끝점 조건이 필요하다. seed 위치만 옮기고 결과 공간을 잘못 해석하면 원하는 방향과 반대로 보일 수 있다.

V3

가중 보로노이 / Power Diagram

일부 조각을 더 크게 남기거나 충격 부근을 더 잘게 만들고 싶을 때.

만드는 방법

일반 거리 대신 power distance ||x−s_i||²−w_i로 소속을 결정한다. 가중치가 큰 seed의 영역을 키울 수 있다. 단순 2D 구현은 seed 쌍의 선형 반평면들을 교차할 수 있다.

나오는 결과

같은 seed 위치에서도 서로 다른 조각 크기. 위치 밀도와 가중치를 독립적으로 제어할 수 있다.

성능 특성

가중 다이어그램에 맞는 알고리즘 또는 추가 구현이 필요하다. 작은 k에서는 반평면 구현을 검토할 수 있지만, 모든 seed 쌍을 처리하면 k²개의 비교가 생기고 다각형 clip 비용도 붙는다.

실패 조건 / 선택의 대가

큰 가중치가 주변 셀을 완전히 없앨 수 있다. 항상 k개 파편이 생긴다는 보장이 없다. UE의 일반 GetVoronoiCells에 가중치 지원이 있다고 가정하지 않는다.

V4

3D 보로노이와 실제 제거 부피의 교차

두꺼운 비정형 물체, 내부에서도 갈라지는 파편이 꼭 필요할 때.

만드는 방법

3D seed로 볼록 셀 부피를 만들고 제거 부피와 3D 교차한다. 새 절단면의 속성·UV·폐쇄성·충돌을 구성한다. 얇은 평면을 잘라낸 후 단순히 두께만 주는 경로와 다르다.

나오는 결과

전면·후면의 파편 윤곽이 다르고 내부 단면이 기울어질 수 있다. 두꺼운 재료에서 2D 압출의 규칙적인 옆면을 줄일 수 있다.

성능 특성

3D 셀 면·교차·Boolean·메시 속성 처리가 필요하며 2D와 동일 비용이라고 볼 수 없다. 실제 엔진 비용은 별도 측정해야 한다.

실패 조건 / 선택의 대가

비폐쇄 메시·아주 얇은 부피·거의 겹치는 면에서 수치 안정성 부담이 크다. 현재 평면 파괴의 첫 선택으로 넣으면 지원 범위가 크게 넓어진다. 기존 2D 경로 재사용률이 낮다.

3 · Seed와 조각 메시를 만드는 세부 선택

셀 생성보다 seed 분포와 교차 이후 정리가 결과를 크게 바꾼다.

파편 수를 먼저 정할지, 크기를 먼저 정할지

고정 seed 수 k는 생성량을 제한하기 쉽지만 작은 구멍과 큰 구멍의 조각 크기가 달라진다. 목표 조각 면적 a를 쓸 경우 k≈Area(Removed)/a로 시작하고 최소·최대 k를 둔다. 다만 교차 후 하나의 셀이 여러 성분으로 갈라지거나 빈 셀이 생겨 최종 파편 수는 k와 다를 수 있다.

교차 이후에는 이 순서를 지킨다

  1. 기존 빈 곳을 제외한 Removed 확정. 여러 영역과 내부 구멍을 보존한다.
  2. 유한 셀을 생성하고 Removed와 교차. 보로노이의 바깥 무한 셀은 영역을 포함한 bounding box로 먼저 닫는다. box clip만으로 복잡한 Removed clip이 끝난 것은 아니다.
  3. 연결 성분 분리·슬리버 정책. 매우 작은 조각을 없애면 Removed를 완전히 덮지 못한다. 인접 조각으로 병합하거나 시각적 생략임을 명시한다.
  4. 공유 경계 정리. 같은 경계의 두 조각이 다른 방향으로 흔들리면 겹침·틈이 생긴다. 공유 edge ID를 기준으로 한 번만 경계 변동을 만들거나 최초 버전에서는 직선 경계를 유지한다.
  5. 구멍을 지원하는 삼각분할·두께 확장. 외곽과 내부 구멍의 방향, 앞뒤 winding, 단면 법선·UV를 맞춘다. 조각의 중심을 빼서 로컬 메시를 만들면 원래 표면 위치로 옮기는 transform을 함께 저장한다.

Interior(Fragment_i) ∩ Interior(Fragment_j) ≈ ∅,  i≠j
Fragment_i ⊆ Removed

공유 경계가 맞닿는 것은 허용하되 면적 겹침은 없어야 한다. 검사 오차는 좌표 단위·양자화·기하 스케일에 맞춰 정한다. 이 문서의 합성 18-seed 예시에서는 세 방식 모두 대칭차 면적과 중복 면적의 절댓값이 10⁻⁶ 예시 면적 단위 미만이었다. UE의 수치 안정성이나 런타임 성공률을 증명한 결과는 아니다.

점 기반·보로노이 방식의 증가 조건

거리 그래프의 최악 전쌍 검사는 n(n−1)/2다. n=64면 2,016쌍, n=512면 130,816쌍이다. 공간 해시는 실제 후보가 작을 때 이를 줄인다. 매 탄착마다 모든 점을 재처리하는 방식과 증분 갱신은 같은 비용으로 비교하면 안 된다.

예시 보로노이 생성기는 각 seed가 다른 seed의 반평면과 교차하므로 k(k−1)회 clip 후보가 있다. k=32면 992회, k=128이면 16,256회다. 각 clip은 현재 다각형 정점 수에도 의존한다. 이것은 예시용 단순 구현의 연산량이며 UE의 Delaunay 기반 구현 복잡도가 아니다.

구멍 없는 단순 파편의 경계 정점 수가 m이고 내부 정점을 추가하지 않으면 앞뒤 면 2(m−2), 측면 2m, 합계 4m−4 삼각형이 필요하다. m=8이면 28개, 그런 파편 32개면 896개다. 구멍·추가 정점·재질 경계·베벨·장식은 제외한 기하학적 계산이며 실제 메시 메모리와 충돌 비용은 별도다.

“빠름/느림”은 같은 입력 범위와 품질일 때만 비교할 수 있다. 단순 셀 조회는 저렴해도 큰 셀 합집합이 비쌀 수 있고, 작은 ROI의 피해장은 점이 많은 전역 재군집화보다 부담이 적을 수 있다. 어느 조합이 우리 게임에서 더 빠른지는 동일 탄착 이력으로 측정해야 한다.
