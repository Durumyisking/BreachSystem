같은 총으로 6발씩 쏴도 탄착점의 배치(3×2, 2×3, 가로/세로 일렬 등)에 따라 브리칭 모양이 달랐다.

가로로 길게 6발을 쐈을 때는 구멍 사이가 비교적 가까워도 브리칭이 안 일어났다.
반대로 위아래 두 줄로 나눠 쏘면 줄 사이가 더 멀어도 브리칭이 일어났다. 총알끼리 연결되는지보다 일정한 범위 안에 탄착점이 모이는지가 중요한 것으로 보인다.
![[20261023160411_1.jpg|678]]

같은 탄착군을 여러 위치에 쐈을 때, UV가 같아 보이는 위치끼리(1·3번 / 2·4번) 브리칭 모양이 같았다.
다른 벽의 동일한 UV 위치에서도 같은 모양이 반복되었다. 손으로 쏴서 탄착점이 완전히 똑같지는 않은데도 같은 결과가 나온 경우가 있었다.
저격총은 같은 UV 영역에서 서로 다른 위치 조합으로 2발씩 총 세 번 쐈는데 모두 같은 브리칭 모양이었다.
![[R6_Experiment_20261023/12_sniper_two_hits.png|400]]
![[20261023161928_1.jpg|544]]

라이플 6발과 근거리 샷건 1발(8펠릿)을 같은 UV 위치에 쐈더니 앞쪽 벽의 큰 브리칭 외곽이 같았다. 뒤쪽이 다르게 보이는 것은 레식 벽이 두 겹이어서 각 판이 별도로 파괴되기 때문이다.
샷건은 거리를 두고 쏘면 펠릿 분산에 따라 결과가 달라졌고, 벽에 바짝 붙어 같은 UV에 쏘면 같은 모양이 반복되었다.

![[13_rifle_six_breach.png|440]]![[14_shotgun_close_breach.png|440]]


비슷한 탄착군에서 Pulse, Vigil K1, Sentry Commando는 같은 결과였지만 Frost 기관단총은 다른 브리칭 모양이 나왔다.

지금까지의 실험으로는 브리칭 발생에 탄착점의 공간적 분포가, 최종 모양에는 UV 위치와 무기 특성도 관여하는 것으로 보인다. 정확한 내부 알고리즘은 아직 알 수 없다.
