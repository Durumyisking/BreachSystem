
#### FGeneralPolygon2d에 Hole을 적용하기위한 절단용 다각형을 만든다. 


- `MakeCircleCutter(Center, Radius, Segments) -> FGeneralPolygon2d`.
- `MakeBoxCutter(Center, Size, Angle) -> FGeneralPolygon2d`.
- `MakeRoughCutter(Center, Radius, Segments, Seed, Roughness) -> FGeneralPolygon2d`.

**처리**: 원의 i번째 점은 Center + Radius×(cos(2πi/N), sin(2πi/N)). 불규칙형은 각도를 순서대로 유지하고 반경을 seed 기반으로 변화시킨다. 음수 반경·3개 미만 정점·자기 교차는 거부한다.

**엔진 API**: FPolygon2d, FMath의 삼각함수, `FRandomStream`. 난수 생성 순서도 고정한다.

**확인**: Radius=20cm, Segments=16인 커터를 벽 중앙에 주황색 선으로 표시한다. 동일 seed는 동일 정점, 다른 seed는 다른 거친 경계다. 아직 벽은 제거하지 않는다.


```cpp
UE::Geometry::FGeneralPolygon2d BreachSurfaceGeometry::MakeCircleCutter(const FVector2d& Center, double Radius, int32 Segments)
{
    FPolygon2d Polygon2d = FPolygon2d::MakeCircle(Radius, Segments, 0.0);
    Polygon2d.Translate(Center);
    FGeneralPolygon2d GeneralPolygon2d(Polygon2d);
    return GeneralPolygon2d;
}

UE::Geometry::FGeneralPolygon2d BreachSurfaceGeometry::MakeBoxCutter(const FVector2d& Center, const FVector2d& Size)
{
    FPolygon2d Polygon2d = FPolygon2d::MakeRectangle(Center, Size.X, Size.Y);
    FGeneralPolygon2d GeneralPolygon2d(Polygon2d);
    return GeneralPolygon2d;
}

UE::Geometry::FGeneralPolygon2d BreachSurfaceGeometry::MakeRoughCutter(const FVector2d& Center, double Radius, int32 Segments, int32 Seed, double Roughness)
{
    FPolygon2d Polygon2d = FPolygon2d::MakeCircle(Radius, Segments, 0.0);
    Polygon2d.Translate(Center);
    // 3. 각 정점에 랜덤 오프셋 적용
    for (int32 i = 0; i < Polygon2d.VertexCount(); ++i)
    {
        const FVector2d Direction = Polygon2d[i].GetSafeNormal();
        const float Offset = FMath::FRandRange(-Roughness, Roughness);
        Polygon2d[i] += Direction * Offset;
    }

    FGeneralPolygon2d GeneralPolygon2d(Polygon2d);
    return GeneralPolygon2d;
}
```
