# Deco 설정

벽의 `SurfaceMaterial` 데이터 에셋에서 `Breach > Decoration`을 설정한다. 별도의 컴포넌트나 Blueprint 이벤트 연결은 필요하지 않다. 에셋을 지정하지 않은 종류는 생성하지 않는다.

## 평면 흔적: Cut Decoration

- `Material`: 일반 Surface 도메인 머티리얼. UV 0~1에 흔적을 그리며, 투명한 외곽은 Masked 또는 Translucent로 준비한다. Deferred Decal 머티리얼은 사용하지 않는다.
- `Padding`: 채택된 커터 경계 상자 바깥 여백. 기본 5cm.
- `SurfaceOffset`: 벽 표면에서 띄울 거리. 기본 0.05cm.

평면 패치는 피격면에만 생긴다. 재파괴 시 사라진 벽 부분만 잘리며, 최초 UV를 유지한다. 같은 면에서 겹치는 영역은 기존 패치가 우선한다. 표면 하나에 앞·뒷면별 최대 하나의 Dynamic Mesh를 사용한다.

## 입체 조각: Feature Decoration

- `Material`: 생성한 판 조각에 적용할 일반 Surface 머티리얼. 미지정이면 생성하지 않는다. 나무의 섬유 사이 빈 부분은 `Masked`의 `Opacity Mask`로 표현한다.
- `MinHoleArea`: 연결된 실제 제거 영역의 최소 월드 면적. 기본 400cm². 작은 구멍들이 합쳐져 기준을 넘은 경우에도 생성한다.
- `Spacing`: 군집 간격의 월드 기준. 기본 19cm. 군집 안에서는 기준의 0.2~0.75배, 군집 사이에는 1.6~3.8배를 사용한다. 2~6개씩 모이며 부착 조건에 따라 생략될 수 있다.
- `Width` / `Length` / `Thickness`: 폭·구멍 안쪽 돌출 길이·뿌리 두께의 월드 기준. 기본 22 / 10 / 1.4cm. 폭·길이는 조각마다 달라지고 끝은 얇아진다. 나무 형상은 폭을 줄이고 길이를 늘려 비교한다.
- `Roughness`: 자유단 길이의 불규칙도. 기본 0.7, 범위 0~1.
- `Seed`: 배치와 형상의 난수 시드. 기본 42. 같은 입력은 같은 결과를 만든다.
- `AtlasSize`: 텍스처 아틀라스의 열·행 수. 기본 1×1. 조각마다 한 셀을 선택한다.

Static Mesh 에셋은 사용하지 않는다. 구멍 경계의 누적 월드 길이를 따라 판을 생성하고, 뿌리는 경계 안쪽의 벽에 조금 겹친다. 일곱 지점의 자유단 굴곡·두께·기울기를 실제 정점과 면으로 만든다. 벽의 로컬 −Y 표면에 한 번 생성하며 앞뒤로 복제하지 않는다. 구멍으로 돌출한 부분은 반대쪽에서도 보인다. Feature 표시는 표면당 하나의 Dynamic Mesh로 합친다.

UV는 각 셀 안에서 U가 폭, V=0이 뿌리, V=1이 돌출 방향이다. 섬유 결은 V 방향으로 준비한다. 나무 마스크는 전체 면에 섬유가 차 있고 곳곳에 빈틈이 있는 형식이며, V에 따른 밀도 변화나 뿌리 전용 불투명 띠를 두지 않는다. 옆면은 같은 마스크를 사용하므로 작은 섬유까지 별도 입체로 모델링되지는 않는다. 머티리얼만 교체하면 기존 정점·배치·UV를 유지한다.

샘플은 `/BreachSystem/Decoration/Materials/M_Deco_Wood`와 `M_Deco_Concrete`이며 `AtlasSize=1×1`로 사용한다. 나무는 승인된 섬유 이미지의 알파를 사용하는 Masked 재질이고, 콘크리트는 마스크를 연결하지 않는 Opaque 재질이다.

부착 구간이 유지되면 조각의 위치와 외형을 보존한다. 부착 구간 일부라도 없어지면 해당 조각 전체를 제거하고 새 경계에 필요한 조각을 배치한다. 원래 벽의 바깥 테두리에는 생성하지 않는다.

## 수명과 코드 입력

직접 피해와 누적 파괴 모두 같은 경로로 자동 처리한다. 설정 에셋 또는 형상 설정값을 교체하면 다음 실제 절삭부터 기존 Deco를 비우고 새 설정을 사용한다. 같은 에셋의 Feature 머티리얼만 교체하면 기존 형상을 유지하며 다음 실제 절삭에 표시 재질을 갱신한다. 실패하거나 면적 변화가 없는 절삭에는 흔적을 추가하지 않는다.

네이티브 호출 `ApplyCutterPolygon(Cutter, Side)`의 `Side`는 `EBreachSurfaceSide::Front` 또는 `Back`이다. 생략 시 로컬 −Y 면인 Front를 사용한다. 실제 피해 경로는 피격 위치에서 가까운 앞·뒷면을 선택한다.

모든 Deco는 충돌·물리·내비게이션에 관여하지 않는다. `ResetSurface`나 표면 파괴로 정리되며, 등록 해제·재등록에서는 기록을 유지한다. 런타임 생성물이며 복제·저장은 제공하지 않는다. 현재 배치의 면적·간격은 절삭 갱신 시 계산한다.

## 검증

빌드는 프로젝트 루트의 `BuildProject_Editor.bat`를 사용한다. 자동화 필터는 `BreachSystem.Decoration`이다. 실제 PIE 검증은 사용자 맵을 건드리지 않도록 별도 unattended 에디터에서 `-BreachDisposablePIE`를 지정한다. `-BreachDecoCapture`를 함께 지정하고 렌더링을 활성화하면 임시 나무결·섬유 마스크 재질로 만든 앞면 불투명/앞면 마스크/뒷면 마스크 화면을 `Saved/Automation/ProceduralDeco/`에 저장한다. 사용자 머티리얼 에셋은 생성·수정하지 않으며, 캡처는 최종 사용자 아트의 품질 검증을 대신하지 않는다.

알고리즘 선택 근거는 [절차적 Deco 알고리즘 조사](Research/Procedural-Deco-Algorithms.md)에 정리한다. R6 외형은 참고이며 이 생성 방식을 R6 내부 구현으로 단정하지 않는다.
