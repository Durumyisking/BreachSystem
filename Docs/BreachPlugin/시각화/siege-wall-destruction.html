벽을 평면에서 자르고,
남은 영역에 두께를 붙인다.

평평한 벽을 정면에서 보면 한 장의 도형이다. 총알이 제거한 영역을 이 도형에서 빼고, 남은 부분의 앞면·뒷면·옆면을 만든다. 겹친 구멍은 함께 제거되며, 무기별 Cut Depth를 정할 필요가 없다.

GDC 2016 공개 원리 참고프로젝트 적용은 설계안오프라인 사용 가능

① 벽을 클릭해서 구멍을 겹쳐 보기

「겹친 피격」과 「테두리 피격」 버튼으로 예시를 불러올 수도 있다.

남은 벽 재료제거된 영역 / 배경피격 입력 도형
피격 입력 0개결과 영역 표시

겹친 피격 예시가 표시되어 있다. 다른 위치를 클릭해도 된다.

② 처리 단계 확인

③ 옆에서 보면: 벽 두께 전체 관통

두께 슬라이더는 원리 설명용이다. 실제 설계에서는 벽 두께를 초기화 후 고정한다. 단면과 두께는 학습용 축척이다.

현재 코드 · 3D Mesh Boolean

현재 3D 벽 메시 − 3D 커터
→ 교차면 계산 → 절단 경계 용접 → 결과 메시

캐시한 길이 1 커터를 Transform으로 늘린다. 월드 Bounds의 정사영으로 관통 길이를 구한다. 기존 구멍 주변에서도 3D 면과 경계가 다시 연산에 참여한다.

반복 피격의 정확한 용접 실패 조건은 아직 확정되지 않았다.

제안 · 평면 벽 전용 경로

현재 남은 2D 영역 − 2D 단면
→ 윤곽 갱신 → 삼각분할 → 벽 두께 생성

이 경로는 3D Boolean 경계 용접에 의존하지 않는다. 2D 폴리곤 연산은 여전히 필요하며, 접점·미세 경계·구멍 삼각분할·충돌·누적 비용을 검증해야 한다.

평면 패널부터 검증하는 설계안이며 런타임에 구현된 기능은 아니다.

이 페이지는 SVG 마스크로 제거 영역의 합쳐짐을 보여준다. 실제 폴리곤 Boolean·삼각분할·Unreal 메시/충돌 생성은 실행하지 않는다. 따라서 연산 성공률이나 성능을 검증하는 도구로 사용하지 않는다.

근거: The Art of Destruction in Rainbow Six: Siege · GDC 2016, 35–40쪽. 평면을 2D로 투영하고 절단·삼각분할 후 두께를 생성하는 공개 설명을 참고했다. 최신 시즈의 전체 구현을 재현한 자료는 아니다.
