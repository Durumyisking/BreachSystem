# 절차적 Deco 미리보기

프로젝트 루트에서 실행한 뒤 [로컬 미리보기](http://127.0.0.1:4178)를 연다.

```powershell
node Docs/BreachPlugin/Prototypes/deco/serve.cjs
```

- **재질 버튼**은 조각의 색·표면·마스크만 바꾼다. 정점·위치·시드는 유지한다. 나무 재질은 섬유 모양의 알파 마스크로 실제로 배경이 보이는 빈 부분을 만든다.
- **나무 섬유 사이 비우기**를 끄면 같은 기하가 불투명한 판으로 보인다. 와이어프레임에서는 마스크를 끄고 실제 삼각형을 표시한다.
- 배치는 좁게 모인 군집과 큰 공백이 섞인다. **평균 배치 간격**은 이 분포의 기준이며 일정 간격을 의미하지 않는다.
- **형상 프리셋**은 비율과 간격만 바꾼다. 선택한 재질과 시드는 유지한다.
- 같은 시드에서 **다시 생성**하면 같은 결과가 나온다. 다른 난수 배치를 보려면 시드를 바꾼다.
- 드래그·휠로 회전·확대한다. 터치에서는 드래그·두 손가락 확대, 키보드에서는 방향키·`+`·`-`를 지원한다.
- 정면·측면·뒷면과 와이어프레임으로 실제 두께, 끝의 굴곡, 벽과 겹친 뿌리를 확인한다.

벽은 비교용 단순 형상이며, 장식은 앞쪽 절단 경계에 붙은 얇은 입체 판으로 생성한다. 평면 흔적, 재파괴, 충돌, Unreal 연결은 포함하지 않는다. 콘크리트·나무 표면은 임시 절차적 텍스처다. R6 내부 구현의 재현을 주장하지 않는다.
