# BreachTest Project Instructions

## Build

- Always build this project by running `BuildProject.bat` from the repository root.
- Do not invoke Unreal Engine's `Build.bat`, `UnrealBuildTool.exe`, or `UnrealBuildTool.dll` directly for this project.
- Do not substitute IDE Build or Live Coding for the required `BuildProject.bat` build unless the user explicitly requests it.
